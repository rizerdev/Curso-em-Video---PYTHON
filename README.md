## 📝 Guia rápido de Markdown

Aqui estão alguns comandos de Markdown que vou utilizar nas anotações das aulas.

### Títulos

- `# Título` → Título grande
- `## Subtítulo` → Título médio
- `### Título menor` → Título menor

### Formatação de texto

- `**texto**` → **Negrito**
- `*texto*` → *Itálico*
- `` `print()` `` → Código no meio do texto

### Listas

- `- item` → Lista
- `1. item` → Lista numerada

### Tarefas

- `- [ ] tarefa` → Tarefa não concluída
- `- [x] tarefa` → Tarefa concluída

### Outros

- `> texto` → Citação ou destaque
- `---` → Linha divisória
