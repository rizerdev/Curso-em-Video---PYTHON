# 🐍 Aula 02 — Para que serve o Python?

## 📜 Origem do Python

O Python começou a ser desenvolvido no final da década de 1980 por **Guido van Rossum**, enquanto ele trabalhava no CWI — Centro de Matemática e Ciência da Computação, na Holanda.

Guido havia participado do desenvolvimento da linguagem **ABC** e queria criar uma linguagem que fosse:

- Simples de aprender;
- Fácil de compreender;
- Organizada;
- Poderosa;
- Capaz de diminuir a complexidade encontrada em outras linguagens.

O desenvolvimento começou em **1989**, e as primeiras versões públicas surgiram no início da década de 1990.

---

## 🐍 De onde veio o nome Python?

Apesar de o símbolo da linguagem lembrar uma cobra, o nome **Python** não foi escolhido inicialmente por causa da serpente.

Guido van Rossum escolheu esse nome como homenagem ao programa de humor britânico:

> Monty Python's Flying Circus

A associação com a cobra se tornou mais forte posteriormente, principalmente depois da publicação de livros sobre a linguagem que utilizavam uma píton na capa.

---

## 🏛️ Python Software Foundation

Em 2001, foi criada a **Python Software Foundation — PSF**, uma organização sem fins lucrativos responsável por apoiar, proteger e promover o desenvolvimento da linguagem Python.

O Python evolui com a participação de sua comunidade. Desenvolvedores podem propor melhorias, discutir mudanças e colaborar com o crescimento da linguagem.

## ⚙️ Principais características do Python

### Linguagem de propósito geral

Python não foi criado para trabalhar somente em uma área. Ele pode ser utilizado em diferentes tipos de projetos, como:

- Sistemas para computadores;
- Aplicações web;
- Automação de tarefas;
- Análise de dados;
- Inteligência Artificial;
- Computação científica;
- Jogos;
- Internet das Coisas;
- Aplicativos;
- Computação gráfica.

Isso não significa que Python seja sempre a melhor linguagem para qualquer projeto, mas mostra que ela é bastante versátil.

### Simples e intuitiva

A sintaxe do Python foi criada para facilitar a leitura e a escrita dos programas.

Seus comandos são próximos da linguagem humana, o que torna Python uma boa opção para quem está começando a programar.

### Multiplataforma

Um programa desenvolvido em Python pode funcionar em diferentes sistemas operacionais, como:

- Windows;
- Linux;
- macOS.

Dependendo do projeto e das bibliotecas utilizadas, poucas adaptações podem ser necessárias.

### Código aberto e gratuito

Python é uma linguagem gratuita e de código aberto. Isso permite que qualquer pessoa possa:

- Utilizar a linguagem;
- Estudar seu código;
- Contribuir com seu desenvolvimento;
- Criar projetos pessoais ou comerciais.

### “Baterias incluídas”

A expressão **“batteries included”** significa que Python já possui uma biblioteca padrão bastante completa.

Com ela, podemos realizar diversas tarefas sem precisar instalar muitas ferramentas adicionais.

### Organização e legibilidade

Python valoriza códigos organizados e fáceis de ler. A indentação — os espaços colocados no começo das linhas — faz parte da estrutura do programa.

Por isso, escrever um código bem organizado não é apenas uma recomendação: é uma característica fundamental da linguagem.

### Orientação a objetos

Python possui suporte à programação orientada a objetos. Na linguagem, praticamente tudo é tratado como um objeto, incluindo números, textos, listas e funções.

Esse conceito será compreendido com mais profundidade durante a evolução dos estudos.

## 🧘 O Zen do Python

O Python possui uma filosofia conhecida como **Zen do Python**, criada por Tim Peters.

Alguns de seus princípios são:

- Bonito é melhor que feio;
- Explícito é melhor que implícito;
- Simples é melhor que complexo;
- Complexo é melhor que complicado;
- A legibilidade conta;
- Erros nunca devem passar silenciosamente;
- Agora é melhor que nunca.

Esses princípios mostram que programar não é apenas fazer o código funcionar. Também é importante criar soluções claras, organizadas e fáceis de manter.

## 💡 Principal aprendizado

Python é uma linguagem simples para iniciantes, mas poderosa o suficiente para ser utilizada em projetos profissionais.

Sua sintaxe legível, sua grande quantidade de bibliotecas e sua comunidade ativa fazem dela uma linguagem adequada tanto para aprender programação quanto para desenvolver soluções reais.

Também é importante respeitar o processo de aprendizagem: antes de criar projetos avançados, precisamos entender bem os fundamentos da programação.
