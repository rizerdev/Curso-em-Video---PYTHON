## O que é uma IDE?

IDE significa **Ambiente de Desenvolvimento Integrado**.

É um programa que reúne ferramentas para escrever, organizar, executar e corrigir códigos.

Uma IDE pode oferecer recursos como:

- Coloração dos comandos;
- Preenchimento automático;
- Identificação de erros;
- Organização dos arquivos;
- Terminal integrado;
- Execução dos programas;
- Depuração do código.

Esses recursos ajudam bastante durante a programação, principalmente quando os projetos começam a ficar maiores.

## PyCharm

O PyCharm é uma IDE criada pela JetBrains e voltada principalmente para o desenvolvimento em Python.

Na aula, foram apresentadas duas versões:

- **Professional:** versão paga e com mais recursos;
- **Community:** versão gratuita, suficiente para estudar Python.

Também foi mostrado como instalar e configurar o PyCharm no Windows, Linux e macOS.

## Minha escolha: GitHub Codespaces

Como estou desenvolvendo meus projetos diretamente pelo GitHub, não precisei instalar o PyCharm.

Estou utilizando o **GitHub Codespaces**, que disponibiliza um ambiente parecido com o Visual Studio Code diretamente no navegador.

Com ele, consigo:

- Criar arquivos Python;
- Escrever meus códigos;
- Utilizar o terminal;
- Executar os programas;
- Organizar as pastas das aulas;
- Salvar tudo no meu repositório do GitHub.

Para executar um programa, posso clicar no botão `▶️` ou utilizar o terminal:

```bash
python3 Aula 04py
```

Por exemplo:

```bash
python3 Desafio 01.py
```

---

## Criando arquivos Python

Todo arquivo que contém um programa em Python deve utilizar a extensão `.py`.

Exemplos:

```text
Desafio 01.py
ex001.py
aula05.py
```

O `.py` identifica que aquele arquivo contém um código escrito em Python.

---

## Testando um programa

Criei um arquivo chamado `Aula 04.py` com o seguinte código:

```python
print("Olá, mundo!")
```

Para executá-lo pelo terminal, utilizei:

```bash
python3 Aula 04.py
```

Resultado:

```text
Olá, mundo!
```

Também posso executar o código utilizando o botão `▶️` disponível no editor.

## Programa com interação

Também posso utilizar o `input()` para receber uma informação do usuário:

```python
nome = input("Qual é o seu nome? ")

print("É um prazer conhecer você,", nome)
```

Ao executar o programa, ele pergunta meu nome e utiliza a resposta na mensagem.

## A importância da prática

Um dos pontos mais importantes da aula foi entender que não é possível aprender programação apenas assistindo aos vídeos.

É necessário praticar, criar os próprios códigos, cometer erros e tentar encontrar as soluções.
