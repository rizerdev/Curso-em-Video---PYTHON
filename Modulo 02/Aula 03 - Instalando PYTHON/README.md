## Como o computador entende nossos comandos?

Nós utilizamos uma linguagem para nos comunicar, mas o computador não consegue entender diretamente o que escrevemos.

O computador trabalha com a chamada **linguagem de máquina**, formada basicamente por sequências de `0` e `1`.

Para explicar isso, o professor utilizou o exemplo de duas pessoas que falam idiomas diferentes. Para que elas consigam conversar, seria necessário colocar um intérprete entre elas.

Na programação acontece algo parecido:

- Nós escrevemos os comandos em uma linguagem de programação;
- O interpretador recebe esses comandos;
- Depois, ele traduz as instruções para uma linguagem que o computador consegue entender.

No nosso caso, precisamos instalar o **interpretador do Python** para que o computador consiga executar os códigos que escrevermos.

---

## Regras da linguagem

Assim como uma pessoa pode não entender determinadas gírias, o interpretador também não entende comandos escritos de qualquer maneira.

Toda linguagem de programação possui suas próprias regras. Precisamos escrever os comandos seguindo a estrutura que o interpretador conhece.

Se escrevermos alguma coisa incorretamente, o Python apresentará um erro. Por isso, é importante prestar atenção na escrita e na organização do código.
